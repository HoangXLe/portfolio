HarvestIQ

Smarter Way for Farmer to Track Crop's Health and Disease

Objectives

Helping Farmers tracking crops' health and diseases

Process

  1. Single-page HTML Field Diagnostics mock (Claude Artifacts) to prove the flow: farm → leaf photo → classify → forecast.
  2. Migrated into a Next.js 15 monorepo (apps/web): dashboard, farms, diagnose, reports, resources, settings. Demo AI runs on /api/diagnose and /api/forecast. Data stays in browser localStorage.
  3. Manual QA across pages, security (no browser API keys, CSP, image/body limits), accessibility, and bug fixes (build, Amplify paths, Maps allowlist).
  4. Push main on GitHub → AWS Amplify Hosting (App Runner was closed to new accounts). Live URL: https://main.d2gy4gwcmsx17c.amplifyapp.com
